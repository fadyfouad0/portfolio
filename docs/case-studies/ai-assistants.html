Le Blog du Dirigeant.

The brief

Le Blog du Dirigeant replaces the single generic chatbot with a team of specialised AI employees, across legal, communication, finance, HR and more.

Overview

Le Blog du Dirigeant wanted to build a SaaS of AI employees, a product they could sell on to other businesses, and reached out to me to design the system. I worked out the model first: nine specialised assistants split by domain, each with a clear role, instead of one chatbot pretending to know everything. Then I designed the product around it, the chat interface, the way conversations stay organised, and the file management that turns a company's own documents into knowledge every assistant can draw on. I built out the design system behind it and took the whole thing responsive, desktop down to phone.

// 01 · Problem

One chatbot can't be an expert at everything.

Businesses need AI support across many domains, legal, HR, marketing, finance, but most tools offer a single generic chatbot with limited context and poor organisation. It's hard to manage conversations, understand what the assistant is for, or give it the company knowledge it needs to answer accurately. The job was to design a clear, intuitive interface that lets people switch between specialised assistants, understand each one's role, keep conversations structured, and upload documents that become shared knowledge across the whole system.

Nine assistants, each a colleague, not a tool.

Every assistant was given a distinct character and a single strong colour. Over time, users associate each one with its face and tone, less like software, more like a team. Three of the nine, Lexi, Verde and Clara, are toured below; the same scaffold holds for all.

// 03 · The build

Every assistant shares one scaffold, only the face, colour and voice change.

Lexi
Lexi · Legal · Web + Mobile

Lexi“Hello, I'm Lexi.”

The conversation opens with a greeting in Lexi's own voice and three starter prompts, the user never faces a blank box.

1

A warm, human welcome

Lexi opens with a friendly, welcoming line before any prompt, a warm first sentence that turns a compliance tool into an approachable colleague from the very first screen.

2

Starter prompts

Ready-made example questions shown up front, so the user sees what the assistant can do and can begin with a single tap instead of a blank box.

Verde
Verde · CSR · Web + Mobile

Verde“Comment puis-je vous assister?”

A row of avatars sits at the top of every conversation, so switching from one specialist to another is a single click, no menus.

1

Seamless switching

The avatar rail keeps the whole team one tap away inside any conversation.

2

One skin per assistant

Every assistant reuses one layout, only the colour and character change.

Clara
Clara · Customer Relations · Web + Mobile

Clara“How can I help you?”

A quiet, focused canvas: the character anchors the view and the sidebar collapses to a single tap for an even wider, distraction-free thread.

1

Focused on the work

The sidebar collapses to a single tap, opening up more room for the conversation and fewer distractions while you work.

2

Colour as memory

Each assistant's colour follows them across the catalogue, chat and avatar, so they're recognised at a glance.

Knowledge base

Documents become knowledge, and stay transparent.

Files can be added at different levels: shared across every assistant, scoped to a subset of assistants, or tied to a single one, so it's easy to control exactly what's in context.

Once uploaded, every answer shows the source it drew from, so responses stay accurate, verifiable and trustworthy.

// 04 · Responsive

One system, every screen.

The catalogue, the chat scaffold and the file system all collapse gracefully into a single thumb-friendly column. Each assistant keeps its colour and character, the language never breaks between desktop and mobile.

// What the design does

It turns a single anonymous chatbot into a team you can actually rely on.

Identity
Face, colour & voice

Each assistant pairs a character, one strong colour and a tone of voice, so the user feels like they're talking to an expert coworker, not a generic chatbot.

Switching
The team, one click away

An avatar rail keeps all nine specialists inside every conversation, so moving between domains never means digging through menus.

Trust
Structured & sourced

Saved threads keep work organised, and uploaded documents become cited knowledge, every answer shows where it came from.
